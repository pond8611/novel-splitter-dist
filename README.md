# Novel Splitter distribution

Download the complete package from the latest release and always open `เปิดโปรแกรมแบ่งตอน.vbs`.

- Keeps each normal input file separate.
- Splits only oversized input files.
- Enforces a UTF-8 hard cap of 12, 13, 14, or 15 KB including header/footer.
- Stages a SHA-256 verified update and applies it on the next launch.
- If the network is unavailable or validation fails, the current HTML remains untouched.

Current release: `splitter-v2`
