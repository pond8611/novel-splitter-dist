# Novel Splitter distribution

Download the complete package from the latest release and always open `เปิดโปรแกรมแบ่งตอน.vbs`.

- Keeps each normal input file separate.
- Auto Quality ranks chapter, scene, transition, paragraph, and sentence boundaries before size.
- Every piece created by a split is at least 6,144 UTF-8 bytes including its generated wrapper.
- There is no forced hard maximum: if no safe natural boundary exists, the splitter keeps a larger piece instead of cutting inside a sentence, word, quote, bracket, or Unicode grapheme.
- Protects multilingual dialogue attribution, common abbreviations, URLs, headings, CR/LF/CRLF, and re-imported generated output.
- Stages a SHA-256 verified update and applies it on the next launch.
- If the network is unavailable or validation fails, the current HTML remains untouched.

Current release: `splitter-v3`
